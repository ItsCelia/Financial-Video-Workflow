# Micron Video Workflow — Prompt Templates

Copy and paste the prompts below into the AI assistant for each phase. Fill in the bracketed placeholders.

---

## Prompt A — Stock / Industry Selection Assistant

```text
你是一名半导体/存储行业研究员。请帮我快速梳理 [股票名称/代码] 的投资逻辑，用于制作一条 60–90 秒的财经短视频。

输出要求：
1. 核心投资 thesis（1–2 句话）。
2. 3–4 个关键催化剂，每个配一个关键数据/时间点。
3. 2–3 个主要风险点。
4. 建议的章节标题（如：行业概览、技术优势、产能布局、财务亮点、风险提示、结论）。
5. 推荐数据来源（公司财报、Wind/iFind/Bloomberg 字段、行业报告等）。

注意：不确定的数据请标注“待核实”，不要编造。
```

## Prompt B — Video Outline Generator

```text
请基于以下研究 brief，帮我生成一条 [时长，如 75 秒] 的短视频分镜大纲。

目标平台：[抖音/小红书/B站/YouTube]
画面比例：[9:16 / 16:9 / 3:4]
视觉风格：[深色科技风/浅色商务风/其他]
字幕：[需要/不需要]
旁白配音：[AI 配音/真人配音/不需要]

输出格式（表格）：
| 场景序号 | 时间轴 | 场景标题 | 旁白文案 | 画面内容 | 关键数据/字幕 | 转场提示 |

要求：
1. 每个场景 3–8 秒，总时长控制在 [X] 秒以内。
2. 必须包含独立的 Intro（开场）和 Closing（结尾/总结）章节。
3. 旁白每句口语化，适合朗读，避免长难句。
4. 画面内容要具体：是数据卡片、时间轴、三栏对比、流程图、还是股票 K 线图。
5. 标注需要重点突出的数字和颜色（如橙色表示增长，青色表示技术节点）。
```

## Prompt C — Preview Frame Generator

```text
现在请为上面的大纲生成静态预览图（preview frames）。

风格要求（必须严格统一）：
- 深色背景（接近 #0B0F17 或深蓝黑），带极 subtle 的径向渐变或光晕。
- 主标题使用大号、粗体、无衬线中文字体，白色或浅灰。
- 小标签/英文使用小写或全大写，字间距加宽，颜色为青蓝色 #38BDF8 或橙色 #F97316。
- 关键数据用橙色或青色高亮，字号明显大于正文。
- 内容卡片为圆角矩形（border-radius 16–24 px），半透明深色底，带细边框或微阴影。
- 图标风格参考 Lucide：线性、简洁、1.5 px 描边。
- 整体版式保持 ample 留白，文字最小 24 px，确保手机端可读。

必须生成的预览图：
1. Intro（开场标题图，含视频主标题、副标题、section label）。
2. 每个主要章节的章节标题图（如技术分析、产能布局、财务表现等）。
3. 关键数据页预览（如 HBM 路线图、DRAM 制程、NAND 层数等）。
4. Closing（结尾总结图，含核心结论或 call to action）。

请先输出这些预览图，等我确认风格后再继续生成完整视频。
```

## Prompt D — Remotion Video Generation Command

```text
预览图已通过。请作为 Remotion 视频生成专家，把上面的分镜大纲和已确认的预览风格转化为可渲染的 React + TypeScript 视频项目。

要求：
1. 使用 Remotion 框架，组件化每个场景。
2. 画面比例 [9:16 / 16:9 / 3:4]，帧率 30 fps，总时长 [X] 秒。
3. 视觉风格完全复用已确认的预览图：深色背景、橙/青强调色、圆角卡片、Lucide 图标、大字号无衬线字体。
4. 每个场景独立成一个 Sequence，添加适当的入场/出场动画（淡入、上滑、缩放、计数动画）。
5. 文字内容必须和 approved 大纲完全一致，避免错别字。
6. 生成项目结构说明和渲染命令（npx remotion render ...）。
7. 默认导出 MP4 H.264；如需其他格式请额外说明。
```

## Prompt E — CapCut Post-Production Assistant

```text
我已经拿到 Remotion 渲染的 MP4，现在需要在剪映里做最终精简和包装。

请帮我：
1. 根据分镜大纲给出每一刀的精简建议（哪些旁白可以压缩、哪些画面可以删减）。
2. 列出本视频需要的补充素材类型（B-roll、动态图表、产品/晶圆厂 footage）。
3. 给出可在剪映中直接搜索的素材关键词（中英文）。
4. 给出可投喂给 AIGC（文生图/文生视频）的具体 prompt，用于生成缺失的 3–5 秒 footage。
5. 列出让静态画面“动起来”的剪映技巧（关键帧、动画、特效、转场、贴纸、音效），并说明使用场景。

视频主题：[主题]
目标平台：[平台]
时长上限：[X] 秒
```
